Flow 1 — UIF · Apartado A y B EXPORT ZIP PRESENTACIÓN MANUAL

Analista
Entra al módulo Reportes → selecciona UIF
↓
Selecciona período (AAAAMM)
↓
Presiona "Generar Apartado A y B"
↓
Presiona "Descargar ZIP"
↓
Sube el ZIP al sistema de la UIF (fuera de la herramienta)
↓
Vuelve y presiona "Marcar como Presentado ✓"
Sistema
Consulta DB → arma archivo Apartado A (saldos) con SQL estándar
↓
Arma archivo Apartado B (operaciones) con SQL estándar
↓
Empaqueta ambos en ZIP
↓
Registra evento EXPORTAR_ZIP en TRACKING_EVENTO
↓
Al marcar: actualiza REPORTE.estado = ENVIADO + presentado_manual = true
↓
Registra evento MARCAR_PRESENTADO en TRACKING_EVENTO
↓
Calendario vencimiento → cambia a VERDE

Flow 2 — BCRA · Base Padrón EXPORT ZIP PRESENTACIÓN MANUAL VÍA RUNOR

Analista
Entra al módulo Reportes → selecciona BCRA
↓
Selecciona período (AAAAMM)
↓
Presiona "Generar Base Padrón"
↓
Presiona "Descargar ZIP" (PADRON.TXT + Detalle.xml)
↓
Sube el ZIP al RUNOR (fuera de la herramienta)
↓
Vuelve y presiona "Marcar como Presentado ✓"
Sistema
Consulta BCRA_NOVEDAD → filtra novedades del período (altas, bajas, modificaciones)
↓
Genera PADRON.TXT en formato BCRA + Detalle.xml
↓
Empaqueta en ZIP
↓
Registra evento EXPORTAR_ZIP en TRACKING_EVENTO
↓
Al marcar: actualiza REPORTE.estado = ENVIADO + presentado_manual = true
↓
Registra evento MARCAR_PRESENTADO en TRACKING_EVENTO
↓
Calendario vencimiento → cambia a VERDE

Flow 3 — ARCA · F.8126 ENVÍO POR WEB SERVICE MARCADO AUTOMÁTICO

Analista
Entra al módulo Reportes → selecciona ARCA
↓
Selecciona período (AAAAMM)
↓
Presiona "Generar F.8126"
↓
Revisa preview (cabecera + cantidad de cuentas/integrantes)
↓
Presiona "Enviar a ARCA"
↓
¿WS responde OK?
Sistema — Flujo OK
Arma ARCA_CABECERA + ARCA_CUENTA + ARCA_INTEGRANTE + ARCA_MOVIMIENTO + ARCA_TRANSFERENCIA desde DB con SQL estándar
↓
Registra evento GENERAR en TRACKING_EVENTO
↓
Llama al WS de ARCA (WSM) con el archivo generado
↓
Guarda respuesta en REPORTE.respuesta_organismo
↓
Actualiza REPORTE.estado = ENVIADO automáticamente
↓
Registra evento ENVIAR_WS resultado OK
↓
Calendario → VERDE · Muestra respuesta del organismo
Sistema — Flujo ERROR
WS devuelve error
↓
Guarda error en REPORTE.respuesta_organismo
↓
Actualiza REPORTE.estado = ERROR
↓
Registra evento ENVIAR_WS resultado ERROR
↓
Calendario → ROJO · Muestra código de error al analista
↓
Analista corrige y reintenta → genera rectificativa (secuencia = 01)

Flow 4 — Calendario de Vencimientos

Analista
Entra al módulo Reportes → ve el Calendario
↓
Identifica reportes pendientes por color
↓
Hace clic en el reporte → va al flow correspondiente (1, 2 o 3)
Sistema
Calcula indicador por período y tipo:
🟢 VERDE = presentado
🟡 AMARILLO = faltan ≤5 días para vencer
🔴 ROJO = vencido o con error
↓
Muestra tabla: UIF A·B / BCRA / ARCA por mes

Eventos Registrados en TRACKING_EVENTO

Evento Disparado por Organismo Descripción
GENERAR Usuario ARCA / UIF / BCRA Se generan los archivos desde la DB con SQL estándar
EXPORTAR_ZIP Usuario UIF / BCRA Usuario descarga el ZIP con los archivos para presentar manualmente
ENVIAR_WS Sistema ARCA Sistema llama al Web Service de ARCA. Resultado: OK o ERROR
MARCAR_PRESENTADO Usuario UIF / BCRA Analista confirma que subió el ZIP al organismo externo. Tick manual.
RECTIFICAR Usuario ARCA / UIF / BCRA Se genera una rectificativa (secuencia = 01+) sobre una presentación ya enviada
